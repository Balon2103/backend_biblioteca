# 📚 MANUALES DEL SISTEMA BIBLIOTECARIO FUPAGUA

## 📋 Descripción General

Este repositorio contiene la documentación completa del **Sistema Bibliotecario FUPAGUA**, desarrollado para la Fundación de Personas Autistas del Guárico. La documentación está dividida en dos manuales especializados para diferentes tipos de usuarios.

---

## 📖 Manuales Disponibles

### 1. 📚 [MANUAL DE USUARIO](MANUAL_USUARIO.md)
**Audiencia**: Usuarios finales, bibliotecarios, administradores del sistema

**Contenido**:
- ✅ Guía paso a paso para usar todas las funcionalidades
- ✅ Instrucciones detalladas para cada módulo
- ✅ Solución de problemas comunes
- ✅ Consejos de uso y mejores prácticas
- ✅ Capturas de pantalla y ejemplos prácticos

**Secciones principales**:
- Acceso al sistema y navegación
- Catálogo de libros y búsquedas
- Sistema de préstamos (interno y externo)
- Panel de administración
- Gestión de miembros y carnets
- Estadísticas y reportes
- Solución de problemas

---

### 2. 🔧 [MANUAL TÉCNICO](MANUAL_TECNICO.md)
**Audiencia**: Desarrolladores, administradores de sistemas, técnicos

**Contenido**:
- ✅ Arquitectura del sistema y tecnologías
- ✅ Instalación y configuración detallada
- ✅ Estructura del proyecto y base de datos
- ✅ API y rutas del sistema
- ✅ Modelos de datos y relaciones
- ✅ Autenticación y autorización
- ✅ Mantenimiento y despliegue
- ✅ Troubleshooting técnico

**Secciones principales**:
- Arquitectura y tecnologías utilizadas
- Instalación paso a paso
- Estructura del proyecto
- Esquema de base de datos
- API y rutas disponibles
- Modelos de datos
- Autenticación y seguridad
- Mantenimiento y backup
- Despliegue en producción
- Debugging y troubleshooting

## 🎯 ¿Qué Manual Necesito?

### Para Usuarios Finales:
- **Bibliotecarios** que usarán el sistema diariamente

- **Personal** que necesita aprender las funcionalidades básicas

**→ Usar**: [MANUAL DE USUARIO](MANUAL_USUARIO.md)

### Para Técnicos y Desarrolladores:
- **Desarrolladores** que trabajarán en el código
- **Administradores de sistemas** que instalarán y mantendrán el sistema
- **Técnicos** que necesitan entender la arquitectura

**→ Usar**: [MANUAL TÉCNICO](MANUAL_TECNICO.md)

1. Leer la [Introducción](MANUAL_USUARIO.md#1-introducción) del Manual de Usuario
